# 排除音乐/K歌后的 H5 衍生产品机会重排

> 日期：2026-06-24
>
> 新约束：雷石已经有一款 K歌 App，并且正在从手机点歌入口引流。因此，手机点歌 H5 内的新衍生产品不应再做“线上 K歌/练歌/录唱”这类主功能，避免和自家 K歌 App 内耗。

## 判断结论

音乐/K歌方向仍然是主线，但应由已有 K歌 App 承接。H5 更适合做三类事：

1. 在 KTV 当场产生可分享、可炫耀、可复访的轻资产。
2. 把包厢多人关系转成下一次组局、分享、复购。
3. 承接唱歌前后 30 分钟的消费和娱乐需求。

排除音乐/K歌后，最值得优先验证的方向是：

| 优先级 | 方向 | 核心理由 | 第一版验证物 |
|---|---|---|---|
| S | 包厢社交资产 | KTV 是多人场景，最缺的是“唱完后还有东西留下” | 包厢战绩卡 / 麦霸榜 / 本场人格 |
| S | 拍照修图与氛围生成 | 用户天然拍照发圈，分享能带自然传播 | KTV 氛围封面 / 朋友圈图 / AI 合照模板 |
| S | 包厢轻互动游戏 | 当场多人反馈强，不依赖安装 App | 猜歌 / 接歌词 / 默契测试 / 真心话 |
| A | 唱后本地生活 | KTV 后天然有夜宵、二场、打车、代驾 | 唱后附近推荐 / 夜宵券 / 返程入口 |
| A | 短剧/娱乐内容联运 | 娱乐心智近，行业增长快，但不宜自建内容池 | 歌曲相关短内容 / 包厢等人内容 |
| B | 潮流/IP/聚会好物 | 年轻人愿为表达和氛围买单，但泛商城风险高 | 聚会道具 / 生日布置 / 麦霸装备 |
| B | 情绪疗愈/压力释放 | 和唱歌的情绪价值相连，但付费需验证 | 唱歌解压报告 / 深夜树洞 |
| C | 出行返程 | 刚需但工具属性强，难形成自有产品心智 | 打车/代驾联运入口 |

## 不建议继续投入的方向

### 1. 线上 K歌主功能

原因：

- 已有自家 K歌 App 承接。
- H5 做复杂录唱体验受性能、权限、音频处理限制。
- 会造成资源分散：用户到底去 H5 还是去 App？

H5 正确角色：

- 给 K歌 App 引流。
- 把线下唱歌数据变成“可分享资产”。
- 在用户有更深唱歌需求时跳转 App。

### 2. 泛音乐播放器/歌单社区

原因：

- 头部平台强，版权和内容壁垒高。
- 与点歌业务关系近，但差异化弱。

H5 正确角色：

- 不做播放器。
- 只做“本场歌单资产”和“唱后分享卡”。

### 3. 泛陌生人社交

原因：

- 合规、安全、风控、骚扰成本高。
- KTV 场景有酒精、夜间、线下门店，风险更高。

H5 正确角色：

- 做同包厢、熟人、半熟人、同店同场景的轻连接。
- 用户必须可控曝光，可一键隐藏/删除。

## 方向 1：包厢社交资产

### 用户场景

一群人唱完歌后，现场气氛很好，但离开后什么都没有沉淀。用户可能愿意保存、转发一个“今晚我们唱了什么、谁最会唱、谁最嗨”的结果。

### 可做产品

- 包厢战绩卡：本场点歌数、合唱次数、热门歌手、气氛峰值。
- 麦霸榜：唱歌最多、被切歌最多、最爱老歌、最会点气氛歌。
- 本场人格：深情派、气氛组、复古派、emo 王、中华曲库。
- 下次组局卡：一键邀请本场成员下次再唱。

### 核心假设

用户不是只想完成点歌任务，也愿意把一次 KTV 聚会变成可分享的社交资产。

### 最小验证

- 入口：唱后页/结账前弹出“生成本场麦霸榜”。
- 成功阈值：曝光点击率 >= 8%，生成完成率 >= 60%，保存/分享率 >= 15%。
- 失败信号：点击率 < 3%，或生成后保存/分享率 < 5%。

### 变现可能

- 会员皮肤/高级模板。
- 门店复购券。
- 生日局/团建局二次预订。
- 品牌联名模板。

## 方向 2：拍照修图与氛围生成

### 用户场景

KTV 有灯光、朋友、聚会、生日、情绪释放，天然适合拍照发朋友圈/小红书/抖音。但用户往往懒得修图、找模板、写文案。

### 可做产品

- KTV 氛围封面：根据门店、包厢、歌曲生成封面图。
- 朋友圈九宫格：本场歌单 + 氛围文案 + 图片模板。
- AI 合照包装：赛博舞台、演唱会海报、复古 MV、港风 KTV。
- 歌曲情绪文案：按本场歌曲生成可发社媒的短句。

### 核心假设

用户愿意为“把今晚唱歌变得更好看、更像一次值得记录的聚会”点击和分享。

### 最小验证

- 入口：本场歌单页展示“一键生成今晚朋友圈封面”。
- 成功阈值：点击率 >= 10%，生成完成率 >= 50%，下载/分享率 >= 20%。
- 失败信号：下载/分享率 < 8%，说明产物表达力不足。

### 变现可能

- 付费模板。
- AI 生成次数包。
- 品牌/门店联名水印。
- 生日/求婚/团建定制模板。

## 方向 3：包厢轻互动游戏

### 用户场景

KTV 经常有等待、冷场、不会唱、抢麦、选歌分歧等碎片时间。多人在同一包厢，天然适合短回合互动。

### 可做产品

- 猜歌挑战：听前奏/看歌词猜歌。
- 接歌词：下一句谁接得快。
- 默契测试：谁最可能点这首歌。
- 气氛组任务卡：给每个人一个轻任务。
- 真心话/大冒险安全版：聚会破冰。

### 核心假设

包厢用户愿意在唱歌间隙玩 1-3 分钟轻互动，且多人参与能提升留存和复购。

### 最小验证

- 入口：点歌等待页放“包厢小游戏，1 分钟开局”。
- 成功阈值：点击率 >= 6%，开局成功率 >= 40%，多人参与率 >= 30%。
- 失败信号：单人点击多、多人开局少，说明不适合包厢协同。

### 变现可能

- 道具/皮肤/称号。
- 包厢排行榜。
- 门店活动赛。
- 品牌赞助挑战。

## 方向 4：唱后本地生活

### 用户场景

唱完歌后，用户常见下一步是夜宵、回家、二场、代驾、附近继续玩。这个需求不一定高频复访，但转化路径短。

### 可做产品

- 唱后夜宵推荐。
- 附近二场/桌游/酒吧/按摩券。
- 打车/代驾入口。
- “下次再唱”门店券。

### 核心假设

用户离店前后 10 分钟有明确的下一站需求，愿意接受与当前门店/地理位置相关的推荐。

### 最小验证

- 入口：结账/离店页展示“唱完去哪儿”。
- 成功阈值：点击率 >= 5%，券领取率 >= 20%，核销率 >= 3%。
- 失败信号：点击但不领券/不核销，说明推荐不够刚需或利益不足。

### 变现可能

- CPS/CPA 联运。
- 本地商家广告。
- 门店复购券包。

## 方向 5：短剧/娱乐内容联运

### 用户场景

KTV 用户处在娱乐心智，等人、排队、唱累、离店路上都有碎片内容消费。短剧行业用户规模大，但 H5 不适合从零做内容平台。

### 可做产品

- 歌曲关联短内容：唱某首歌后推荐相关影视片段/短剧。
- 等人内容流：包厢等待时 30-90 秒内容。
- 主题歌单 + 短剧联动：失恋局、生日局、怀旧局。

### 核心假设

用户愿意在 KTV 前后消费轻娱乐内容，但内容必须和当前情绪/歌曲/聚会主题有关。

### 最小验证

- 入口：等人页/唱后页展示“和你今晚歌单匹配的短内容”。
- 成功阈值：点击率 >= 5%，完播率 >= 25%，跳转转化 >= 3%。
- 失败信号：点击率低，说明内容与 KTV 心智连接弱。

### 变现可能

- 内容平台联运。
- 广告分成。
- IP 联名活动。

## 方向 6：潮流/IP/聚会好物

### 用户场景

年轻人愿意为情绪价值、身份表达、聚会氛围、IP 联名买单。但 KTV H5 不应做泛商城。

### 可做产品

- 生日局布置包。
- 聚会拍照道具。
- 麦霸装备：麦克风、耳返、声卡、氛围灯。
- 歌手/IP 主题周边。

### 核心假设

用户愿意在明确聚会场景下为“气氛更好、照片更好看、身份更鲜明”的小商品付费。

### 最小验证

- 入口：订房后/到店前展示“今晚聚会加点料”。
- 成功阈值：点击率 >= 4%，加购率 >= 2%，客单价可覆盖履约成本。
- 失败信号：点击低或履约复杂，说明不适合早期投入。

## 最推荐先做的 3 个实验

### 实验 A：包厢战绩卡

- 为什么先做：最贴合点歌数据，技术依赖低，分享潜力高。
- 入口：唱后页/结账页。
- 验证目标：用户是否愿意把一次 KTV 消费保存为社交资产。

### 实验 B：KTV 氛围封面

- 为什么先做：拍照分享是年轻人强行为，且能自然传播门店。
- 入口：本场歌单页。
- 验证目标：用户是否愿意下载/分享 H5 生成内容。

### 实验 C：包厢猜歌/接歌词

- 为什么先做：多人场景强，能提升当场时长和气氛。
- 入口：点歌等待页。
- 验证目标：包厢多人是否愿意一起玩轻互动。

## 资料信号

- QuestMobile 2026 短剧行业报告显示，短剧行业月活用户规模已达 7.18 亿，独立 App 与微信小程序均高速增长。
- PwC《全球娱乐及媒体行业展望 2025-2029：中国摘要》提到，中国社交/休闲类游戏收入占电子游戏总收入比重高，且内置广告是重要驱动。
- 美团/新华网 2025 年生活服务趋势内容提到，年轻人更重视“情价比”、线下体验和本地玩乐；自助 KTV、无人歌房等业态有明显增长。

## 下一步

不要同时开 6 个方向。建议先做一轮 H5 fake-door：

1. 在同一批门店/流量里同时放 3 个入口：战绩卡、氛围封面、包厢小游戏。
2. 每个入口只做点击和生成页，不做完整产品。
3. 7 天后按点击率、生成完成率、保存/分享率、多人参与率排序。
4. 第一名进入 MVP，第二名保留，第三名降级或放弃。
