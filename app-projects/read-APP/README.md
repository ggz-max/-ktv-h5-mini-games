# 阅读 H5 - 静光手绘

基于 `project/阅读首页-静光手绘/index.html` 升级的动态交互 H5 原型。

## 交互范围

- 底部导航：切换首页、书架、发现、我的。
- 首页：首屏只保留今日阅读目标、继续阅读、专注入口、只读今日状态和两本差异化“今日可读”；默认继续读《论语》，继续读卡片显示当前位置百分比、真实章节和读到第几页，今日推荐优先展示真实公版作品，复习、书单和工具快捷入口交给我的页和阅读器，避免中部空面板抢占阅读内容；今日分钟按本地日期记录，隔天打开会重置今日状态，首页不再用签到点击伪造阅读分钟。
- 内容资源：书库新增《论语》《道德经》《庄子》《孟子》《诗经》《唐诗三百首》《浮生六记》《聊斋志异》《西游记》《红楼梦》《三国演义》《史记》《水浒传》《儒林外史》《世说新语》《山海经》《古文观止》《楚辞》《搜神记》《镜花缘》《西厢记》《牡丹亭》《菜根谭》《颜氏家训》等真实公版作品，并把首页、默认书架、收藏、离线、笔记种子、发现资源库和搜索结果切到公版/导入内容；少量原型样章仅作为 UI 场景和内部交互 fixture，不进入主资源库。
- 数据资源：新增 `data/catalog.json` 静态书库，部署到服务器后页面会优先通过 `fetch("data/catalog.json")` 加载公版资源；直接打开 HTML 或数据不可用时保留内置书库兜底。外部书库新增《资治通鉴》《孙子兵法》《三字经》《千字文》《笠翁对韵》《幼学琼林》《战国策》《国语》《左传》《礼记》《孝经》《易经》《蒙求》《徐霞客游记》《东坡志林》《笑林广记》等真实公版条目。
- 内容矩阵：专题负责策划主题，个人书单负责使用场景，月度书单负责续读安排；QA 会检查各入口书籍组合不能完全重复、重叠率不能过高，并要求每本 MVP 图书和公版作品都有独立阅读页；全部公版书不低于六个可读单元，且同一本书内目录标题不重复，避免停留在浅样章或凑数页。
- 发现：资源库搜索、搜索灵感/最近搜索、公版/经典/诗词/小说/笔记/志怪/戏曲/短读/历史/兵法/蒙学/游记等分类筛选、阅读榜单、编辑专题书单、作者小径、图书详情、加入书架；分类筛选后资源库结果会直接出现在筛选说明下方，资源卡直接显示来源、版权说明和短样章，作者小径默认展示孔子、老子、庄周等真实公版作者，榜单和专题作为后续探索内容；作者动态、共读房间和阅读路径已从前台与静态数据中移除。
- 搜索发现：提供公版经典、睡前短读、晨读、唐诗、生活笔记、古典小说、志怪夜读、戏曲曲词等搜索灵感；输入后在搜索框下方直接展示唯一一组搜索结果、命中数量和“搜索范围：全库”说明，手动输入会回到全库范围，最近搜索只保存用户选择或清空确认后的完整关键词，不记录输入过程中的半截词。
- 来源与版权：公版作品在详情和资源卡中标注“维基文库”和“公版古籍，维基文库收录”，并保留来源 URL；MVP 只选古典公版作品，不纳入近现代版权状态复杂的文本，降低演示内容版权风险。页面会显示当前书库来源，便于区分服务器数据和内置种子。
- 阅读榜单：提供本周热读榜、新书小径榜、短读完成榜、志怪夜读榜和曲词摘句榜，可打开榜单、查看榜首详情，并一键加入榜单图书。
- 专题/作者：编辑专题可展开完整书单并一键加入整套书，“看同类书”会回到发现页展示对应分类；作者页优先服务公版作者入口，展示代表作并一键收进书架，不再维护关注/取消关注这类社交状态。
- 复习盒：把笔记和划线自动组织成书摘复习卡，可标记“记住了”，并同步今日分钟。
- 阅读数据中心：展示本周阅读节奏、阅读日历、安静成就、主题偏好、日均分钟、笔记/划线数据，并可生成周报摘要保存到笔记。
- 阅读日历/成就：按最近 7 天阅读分钟生成日历反馈，根据笔记、划线、完读和书单整理点亮轻成就，并可保存今日复盘。
- 底部抽屉：只保留新笔记、加入书架、缓存、读后感受、保存摘要等具体动作，不再放“打开某某页面”这类兜底跳转按钮。
- 书架：只展示已加入书架的书，支持全部、在读、待读、读完筛选；筛选状态由实时阅读位置派生，不再依赖图书初始状态；每行显示当前位置百分比、读到第几页、在读/待读/读完状态和开始/继续/回看动作，收藏状态以标签显示，不遮挡主动作；书名区域打开详情，右侧主按钮进入阅读器，避免整行隐形跳转造成误触。
- 个人书单：书架按晨读经典、睡前短章、草木山水、古典名著长读、曲词摘句、志怪夜读等场景整理图书；书单卡和详情会显示在读本数与最高当前位置，保存过阅读页码的书会计入在读，支持打开书单、固定书单、从详情加入书单，并整组离线。
- 书架管理：支持真实入架顺序的最近加入、位置优先、短读优先排序；筛选结果会直接显示在筛选控件下方，并用摘要说明当前筛选规则、排序方式和各状态数量，提供个人书单、导入书籍和离线书包入口。
- 书籍导入：支持粘贴 TXT 正文生成本地书，导入后自动进入书架和离线书包，拥有按段落切分的独立正文页，并支持阅读器、阅读位置、笔记和划线；样章仅作为空数据试用入口。
- 离线书包：可从资源库、书籍详情或书架管理缓存/移除书籍，缓存状态会在列表和详情中同步显示。
- 阅读器：顶部只保留返回、目录和阅读设置，避免正文首屏出现弱交互工具堆叠；核心链路保留翻页、目录跳转、字号设置、护眼/纸色/夜间主题、段落划线、高亮回显、段落笔记，并同步当前书位置；阅读器顶部副标题、首页当前书卡和书架行都会显示真实继续阅读章节，底部只显示一个“当前位置”条，详情/书架显示读到当前页的位置，继续阅读会按位置反推并保存对应页码，目录/搜索保存的当前位置也会被视为可继续阅读，顺序翻到最后一页即显示并保存 100%，写小结只负责生成完读记录，目录跳转只改变当前位置、不会自动标记完读，第一页点击上一页会停留在第一页；偏好里的翻页计时关闭后只停止累加今日分钟，不会停止保存阅读位置；点正文段落会选中该段，每段旁提供划线和笔记按钮，底部划线/笔记按钮也会作用于当前选中段落，笔记会带入对应段落文本与来源。
- 专注阅读：从首页选择 10/18/30 分钟专注阅读，完成后记录专注时长、推进当前位置和继续阅读位置，并同步阅读日历。
- 完读小结：顺序读到最后一页后当前位置到 100%，可通过明确的“写小结”按钮进入完读抽屉，优先写读后感、回到复习盒整理书摘，再选择下一本继续读；历史评分数据仅做兼容，不在详情或读后感列表展示分数，榜单和资源卡改用页数、分钟、来源和在读人数等阅读指标。
- 书籍详情：在读人数、推荐理由、试读句、作者入口、阅读记录、读后感受、继续阅读/从头阅读、作者代表作入架、加入或移出书架、收藏或取消收藏；有当前位置或已保存阅读位置的书点击从头阅读会先进入确认弹层，确认后才把当前位置回到第一页，笔记、划线、收藏和读后感受保留。
- 我的：阅读目标、今日分钟、书架/收藏/笔记/划线统计、阅读数据中心、阅读日历、复习盒、作者作品、个人书单、导入书籍、离线书包、阅读偏好、目标调整、书摘整理、阅读复盘、书摘卡片、月度书单。笔记入口可直接写新笔记，草稿会持久化；书摘卡片复制后会显示可手动复制的完整文案，月度书单会按继续读、本月短读和下月候选实时分组，不再用生成/刷新按钮伪造状态；只要保存过阅读位置，即使当前位置仍为 0%，也会进入继续读而不是未读短书，并可把候选公版书加入书架。
- 阅读偏好：可设置默认阅读主题、安静模式和翻页计时；安静模式会减少运营提醒，阅读位置和进度始终自动保存。

## 小团队闭环打磨

- 产品：收缩首页为“继续读 + 今日可读”的 MVP 首屏，移除首页半截路径/工具面板和抽屉兜底跳转；补齐从搜索灵感、发现图书、差异化书单矩阵、阅读榜单、专题书单/作者页、加入书架/个人书单/离线缓存/本地导入、进入阅读、专注阅读、书内查找、划线/笔记、完读小结、读后感受弱记录、书摘复习、阅读数据、阅读日历/成就、收藏、查看统计到调整目标的主链路；首页今日状态只展示真实今日分钟，不再提供签到加分钟，隔天会从新的本地日期重新开始；翻页计时偏好只影响今日分钟，不影响阅读器进度保存。
- 体验运营：用“今日计划、专注阅读、搜索灵感、阅读榜单、专题书单、作者小径、个人书单、完读小结、书摘复习、阅读数据中心、阅读日历、安静成就、编辑书单、推荐理由、睡前短读、城市微旅行、生活整理、阅读复盘、月度书单”等轻运营位替代商业化入口，并删掉发现页前台的作者动态、阅读路径、共读房间和读友短评，保持慢阅读氛围。

## 视觉实现

- HTML/CSS：标题、正文、列表、按钮、底部导航、底部抽屉、阅读器、toast、进度条。
- 图片素材：`assets/scene-right.png` 用于右侧窗边手绘氛围层；`assets/*.svg` 用于书封和推荐缩略图。

## 验收资料

- `index.html`：动态 H5 原型。
- `data/catalog.json`：可部署的静态书库和书单资源。
- `bbox.json`：含动态视图、阅读器、底部抽屉和反馈层标注。
- `asset-manifest.json`：素材清单。
- `preview.png`：浏览器回看截图。
- `qa-check.js`：关键产品链路自动验收脚本。
