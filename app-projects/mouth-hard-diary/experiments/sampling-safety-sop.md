# 真实采样安全 SOP

这份 SOP 用来约束“嘴硬日记 / 发疯报告”的真实用户采样。它不是法律意见，而是 MVP 阶段的现场执行边界，目的是避免把娱乐表达误做成心理诊断、隐私采集或高风险干预。

## 采样前必须确认

- `npm run verify:launch` 通过后才允许对外采样。
- UI 图片已从 Pencil `.pen` 导出，H5 不再使用临时预览图。
- runtime 已通过 `npm run sampling:prepare -- --yes` 备份并清空。
- 现场人员已读 `experiments/field-sampling-playbook.md` 和本 SOP。
- 页面和口头说明都明确：匿名采样，不收真实手机号、微信或身份信息。

## 现场口径

可以说：

> 我们在测一个轻内容小工具，会把今天的烦事生成一张可保存的“精神状态报告”。这是娱乐表达，不是心理诊断或建议。过程大约 1 分钟，只记录匿名点击、生成结果和反馈，不收真实手机号、微信或身份信息。

不要说：

- “这个能看出你的真实心理状态。”
- “这个可以治愈 / 缓解焦虑。”
- “留下联系方式后我们给你做后续分析。”
- “你把真实经历写详细一点。”

## 隐私边界

允许记录：

- 是否输入了文字。
- 输入长度。
- 选择的场景、风格、入口 variant。
- 是否保存、分享、复制、重新生成。
- 对内容的匿名反馈。
- 访谈中的概括性原因，例如“工作压力”“失恋嘴硬”“怀旧情绪”。

禁止记录：

- 用户输入框里的原始文本。
- 真实姓名、手机号、微信号、身份证、学校、公司、住址。
- 可识别具体第三方的信息。
- 截图中的聊天记录、通讯录或个人资料。
- 用户明确不想留下的任何反馈。

## 年龄和场景

- 优先采样 18 岁以上用户。
- 如果无法确认对方已成年，只做内部演示，不纳入真实结论。
- KTV/聚会场景要避免在用户明显醉酒、情绪失控或被同伴催促时采样。
- 不要让同伴围观用户输入内容。

## 冒犯和不适处理

如果用户觉得冒犯、不准、水尬或像广告：

1. 不解释、不辩护。
2. 引导用户点击“不舒服/有点冒犯”反馈。
3. 访谈只记录概括：是哪类句子、哪种风格、哪个场景造成不适。
4. 当晚复盘时优先检查对应内容模板。

现场话术：

> 收到，这类反馈对我们很重要。我们不会记录你的原文，只记录这是哪类表达让你不舒服。

## 危机或自伤表达

如果用户主动表达自伤、伤害他人、强烈绝望或现实危险：

1. 立即停止把这件事当成娱乐内容采样。
2. 不继续追问细节，不要求用户输入更多内容。
3. 建议用户联系身边可信的人，或寻求当地紧急服务 / 专业热线。
4. 如果现场有同行朋友或工作人员，优先让可信的人陪伴用户。
5. 后台只记录“出现高风险表达，已停止采样并建议求助”，不记录原话。

现场话术：

> 这个情况不适合继续当成娱乐内容来测。你可以先联系身边可信的人；如果有现实危险，请优先联系当地紧急服务或专业热线。

## 留资和 App 假门

当前 MVP 只记录意向：

- `wechat`：愿意微信提醒。
- `phone`：愿意手机号提醒。
- `skip`：先不用。

禁止现场收集真实联系方式。真实留资需要单独补隐私授权、存储、删除和撤回机制。

## 复盘边界

当晚复盘可以看：

- 保存率、分享率、二次生成率。
- App 兴趣第一名。
- `accurate` / `off` / `uncomfortable` 反馈。
- 访谈中的匿名概括。

当晚复盘不能做：

- 用本地验证数据做真实结论。
- 根据单个强反馈直接决定深做 App。
- 把用户原始输入复制到 `docs/runtime-review.md`、`docs/founder-brief.md` 或 `product/post-sampling-backlog.md`。
- 把危机表达改写成搞笑内容。

## 停止采样条件

出现以下任一情况，当天停止继续采样，先复盘：

- `verify:launch` 没通过。
- Pencil 最终切图缺失或仍是 `temporary_preview`。
- runtime 混入本地验证数据。
- 连续 2 个用户认为内容冒犯或像心理诊断。
- 现场出现自伤、伤害他人或现实危险表达。
- 有用户质疑隐私采集且现场无法解释清楚。
