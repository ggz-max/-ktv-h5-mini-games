# MVP PRD：今日发疯报告

## 1. 产品概述

今日发疯报告是嘴硬日记的 H5 MVP。用户通过 3 步输入当天状态，生成一张可保存、可分享的“精神状态报告”。

## 2. 目标

验证用户是否愿意：

1. 点击“生成发疯报告”入口。
2. 输入或选择自己的情绪状态。
3. 查看生成报告。
4. 保存或分享报告。
5. 产生再次生成或下载 App 的意愿。

## 3. 非目标

MVP 不做：

- 完整 App。
- 严肃心理测评。
- 陌生人社区。
- 长日记编辑器。
- 多轮 AI 陪聊。
- 复杂图片编辑器。

## 4. 用户流程

1. 首页：用户看到主张“把今天的破事翻译成精神状态报告”。
2. 情绪选择：选择今天主要破事。
3. 风格选择：选择嘴硬风格。
4. 短输入：可选输入一句真实想法。
5. 生成中：展示“精神状态正在加载”。
6. 结果页：展示称号、报告文案、三条解释、今日建议。
7. 分享页：保存图片、复制文案、下载/唤起 App。

## 5. 输入设计

H5 输入项从后端配置接口动态获取：

```http
GET /api/v1/mouth-hard/config
```

前端保留 fallback 选项，避免配置接口异常时页面不可用。

### 5.1 破事类型

- 上班/上学受气
- 失恋/暧昧失败
- 朋友关系内耗
- 深夜 emo
- 未来焦虑
- 怀旧突然袭击
- 钱包状态异常
- 什么都没发生但就是累

### 5.2 嘴硬风格

- 体面崩溃
- 打工人发疯
- 失恋嘴硬
- 阴阳怪气
- 人间清醒装死
- 抽象乱码
- 温柔自救

### 5.3 可选短输入

占位文案：

> 比如：今天真的很累，但我不想承认。

限制：

- 最多 80 字。
- 可跳过。
- 分享图片默认不展示原文。

## 6. 输出设计

### 6.1 今日称号

示例：

- 体面崩溃观察员
- 嘴硬型脆皮人类
- 精神离线维护中
- 上班暂停做人代表
- 深夜 emo 合法持证人

### 6.2 主文案

要求：

- 20-40 字。
- 像朋友替用户说话。
- 有梗，但不过度阴暗。

示例：

> 你不是没事，你只是把崩溃调成了静音模式。

### 6.3 三条解释

结构：

- 今天的表面状态。
- 今天的真实状态。
- 今天的嘴硬方式。

示例：

- 表面：还能回消息，甚至会发表情包。
- 真实：心里已经开了三次庭。
- 嘴硬：没关系，我只是暂时不想做人。

### 6.4 今日建议

轻、短、不说教：

- 先别复盘人生，先喝口水。
- 今天不适合做重大决定，适合洗澡睡觉。
- 允许自己离线 20 分钟。

### 6.5 分享海报元素

- 产品名：嘴硬日记。
- 日期。
- 今日称号。
- 主文案。
- 情绪能量条。
- 二维码/下载 App 入口占位。

## 7. 页面清单

| 页面 | 目的 | 关键组件 |
|---|---|---|
| 首页 | 建立兴趣 | 主视觉、标题、生成按钮、样例卡 |
| 选择页 | 获取输入 | 破事类型、风格选择、短输入 |
| 生成页 | 增加仪式感 | 加载文案、进度动画 |
| 结果页 | 核心价值 | 称号、文案、解释、保存分享 |
| App 承接页 | 转化 | 历史档案、称号墙、下载按钮 |

## 8. 内容安全

### 高风险输入

包括：

- 自杀、自伤。
- 伤害他人。
- 明确暴力威胁。
- 未成年人危险处境。

处理：

- 不生成玩笑化内容。
- 展示温和提示和求助建议。
- 可提供紧急联系方式占位，由运营按地区配置。

### 普通负面输入

包括：

- 失恋、焦虑、工作压力、朋友内耗。

处理：

- 可以幽默转译。
- 不扩大负面情绪。
- 不鼓励报复、骚扰或冲动行为。

## 9. 成功指标

| 指标 | 目标 |
|---|---:|
| 首页按钮点击率 | >= 10% |
| 输入完成率 | >= 50% |
| 生成完成率 | >= 85% |
| 保存图片率 | >= 20% |
| 分享率 | >= 12% |
| 二次生成率 | >= 25% |
| App 下载/承接点击率 | >= 5% |
| 微信/手机号提醒意向率 | >= 2% |

## 10. 失败信号

- 点击率低于 3%：入口价值不明显。
- 输入完成率低于 30%：流程太重或选项不对。
- 保存率低于 8%：输出不够好看或不够“说中我”。
- 分享率低于 5%：文案不够社交化。
- 高风险输入比例异常：需要重新评估入口和文案边界。

## 11. H5 与 App 承接

H5 做：

- 今日发疯报告。
- 单次报告海报。
- 下载/唤起 App。
- App 功能兴趣和上线提醒意向采样。

App 承接：

- 每日发疯档案。
- 嘴硬人格图鉴。
- 私密日记。
- 风格模板。
- 好友共鸣。
- 会员高级报告。

MVP 留资边界：

- 当前只记录 `wechat` / `phone` / `skip` 的选择意向。
- 不收集真实手机号、微信 OpenID 或联系方式。
- 进入真实灰度前，必须补隐私授权、数据存储、删除和导出机制。
