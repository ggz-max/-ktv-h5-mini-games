# UI 设计简报

## 产品气质

嘴硬日记的 UI 不能像心理咨询，也不能像普通日记本。它应该像一个深夜打开的、带一点荒诞感的精神状态仪表盘：

- 亲近。
- 好笑。
- 有一点发疯。
- 但不阴暗、不压抑。

## 关键词

- 嘴硬
- 精神状态
- 发疯报告
- 体面崩溃
- 深夜便利贴
- 电子树洞
- 抽象但可爱

## 视觉方向

推荐方向：**深夜便利贴 + 霓虹批注**

理由：

- 适合情绪表达，但不医疗化。
- 便利贴、手写批注、胶带、进度条能形成“报告感”。
- 霓虹色和深色背景能承接年轻人的夜间情绪场景。
- 既能做 H5，也能延展成 App 的视觉系统。

## 色彩

避免单一紫蓝或纯暗黑。建议：

- 背景：近黑紫灰 `#17151F`
- 主卡：暖白便签 `#FFF2D8`
- 强调绿：酸性青绿 `#B7FF5A`
- 强调粉：热粉 `#FF5C9A`
- 辅助蓝：电光蓝 `#5AC8FF`
- 文本深色：墨黑 `#1E1A22`
- 次级文本：灰紫 `#A8A0B5`

## 字体风格

- 标题：粗、有压迫感，但不要恐怖。
- 正文：清晰易读。
- 局部使用手写/批注感元素，但 H5 内正文不要依赖手写字体。

## 页面首版

Pencil 先设计 3 个移动端画面：

1. 首页：主张 + 样例报告卡 + 生成按钮。
2. 输入页：破事类型 + 嘴硬风格 + 短输入。
3. 结果页：今日称号 + 精神状态报告 + 保存分享按钮。

尺寸：

- 移动端 390 x 844。

## 插画/图片资产

需要 Pencil 生成并导出的 UI 图片：

- 首页主视觉：一张“精神状态报告卡”拼贴图。
- 结果页装饰贴纸：离线维护、嘴硬值、精神电量等小贴纸。
- 分享海报背景：可复用为 H5 结果卡背景。

## 交互要求

- 首页 3 秒内知道要做什么。
- 输入页不超过 3 步。
- 结果页第一屏必须看到称号和主文案。
- 按钮稳定尺寸，文案不换行溢出。
- 分享和保存按钮用清晰图标。

## 禁忌

- 不使用医疗、心理咨询、冥想类视觉。
- 不使用大面积单一紫色渐变。
- 不使用恐怖、血腥、重度抑郁视觉。
- 不把结果写得像诊断。
