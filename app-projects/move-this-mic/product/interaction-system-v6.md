# 挪开这个麦 v6 手势玩法系统

## 目标

v6 不再把所有物件统一处理成“点击或拖进撤离区”。第 4 关起，物件通过统一的 `interaction` 字段获得不同触控规则，后续关卡可以复用和组合，而不需要为每关重写流程。

## 七类操作

| interaction | 玩家动作 | 完成条件 | 主要物件 |
|---|---|---|---|
| `hold` | 长按 | 按住 0.75-0.9 秒，提前松手失败 | 手机、遥控器 |
| `scrub` | 左右往返 | 达到 3-6 次有效换向 | 线结、防滑垫 |
| `pour` | 拖动并停留 | 拖到排水位，保持 0.7-0.85 秒 | 冰桶 |
| `shake` | 左右摇动 | 达到指定幅度和换向次数 | 沙锤 |
| `trace` | 沿线捋动 | 从线头开始，一次滑到线尾 | 麦线 |
| `carry` | 稳定搬运 | 先穿过安全门，再进入撤离区 | 满杯、气泡饮 |
| `rhythm` | 卡节拍 | 移动亮点进入绿色窗口时按下 | 荧光棒 |

## 关卡编排

| 关卡 | 机制组合 |
|---|---|
| 1-3 | 保留点击、基础拖拽与路线教学 |
| 4 | 长按手机 -> 往返解结 -> 沿线捋线 |
| 5 | 卡点加时 + 冰桶倾倒，或长按遥控器 + 安全搬杯 |
| 6 | 擦拭泄压 + 解结 + 捋线，或安全搬杯 + 长按 + 捋线 |
| 7 | 两条路线分别组合搬运/长按/往返/捋线 |
| 8 | 左路卡点，右路直接起手；两路都要往返解结和捋线 |
| 9 | 三路线混合倾倒、摇动、擦拭、长按、解结和捋线 |

## 反馈规则

- 每个特殊物件显示动作标签，操作过程中显示独立进度条。
- 长按和倾倒提前松手不会计入动作，但需要重新完成。
- 往返和摇动进度可以分段保留；捋线必须从线头一口气完成。
- 安全搬运跳过安全门不会移除物件。
- 节拍失误增加 6 点缠线值并损失无失误三星资格。
- 特殊动作完整完成后才记 1 步，仍受关卡动作上限约束。

## 素材

- 冰桶使用 image2 生成的真实透明物件素材：`frontend/public/assets/image2/items/bucket.webp`。
- 其余机制继续复用遥控器、线结、麦线、杯子、沙锤、荧光棒等真实物件精灵。

## 自动验证

- 长按提前松手不能移除物件。
- 往返操作的半程进度必须保留，完成次数后才能移除。
- 捋线完成后才解锁后续物件。
- 节拍命中必须获得加时。
- 冰桶拖到排水位并停留后才能完成倾倒。
- 杯子直接点击无效，穿过安全门后才能撤离。
- 沙锤达到摇动次数后才能移除。
- 九关完整通关、存档和 390x844 / 360x740 布局继续通过。
