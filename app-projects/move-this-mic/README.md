# 挪开这个麦

## 项目定位

挪开这个麦是一款放在 KTV 手机点歌 H5 入口里的轻量顺序解谜小游戏。

一句话：

> 杯子、遥控器、麦线全压在一起。按正确顺序挪开物件，救出被卡住的麦。

## 为什么做这个

- 遵循 `decisions/0003-lightweight-copyable-minigame-benchmarking.md`：轻量、可快速复制、必须有成熟小游戏母体。
- 参考 `打个螺丝`、挪车、解绳、顺序解锁类小游戏：玩家要判断“哪个东西现在能动”，错了会被卡住。
- 和 `包厢大扫除` 不重复：它不是清理同类物品或消除，而是顺序拆解和局部依赖判断。
- KTV 入口语境直观：麦克风线、遥控器、杯子、骰子、零食盘都是包厢里看得懂的物件，男性用户也能理解挑战感。

## 当前阶段

MVP 已完成：

- `research/benchmark-and-mechanics.md`：爆款母体与机制换皮说明。
- `product/mvp-prd.md`：MVP PRD，明确 H5 与 App 分工。
- `frontend/`：可玩的静态 H5。
- `scripts/`：构建与本地验证脚本。
- `verification/`：本地验证截图输出目录。

v2 已按“玩法太无聊”的反馈调整：

- 去掉局内明牌答案，不再直接告诉玩家下一个该挪谁。
- 每关开局增加多条可选路线，让玩家先判断而不是按提示走。
- 误触会扣时并提升麦线压力，压力爆表直接失败。
- 危险物件会涨压力但给额外分，形成“稳一点/冲分”的选择。
- 连续挪对显示连拆反馈，结果文案记录最高压力。

v3 已按“不能只改封面，局内元素也要设计”的反馈调整：

- 通关目标从“清空整桌”改成“救出目标麦”，每桌提供安全路线和冒险路线。
- 最短步数决定星级；连续挪对 3 次增加 3 秒，绕路会影响最终表现。
- 入口主视觉、游戏桌面和 12 类局内物件全部使用 image2 生成并做 WebP 轻量化。
- 麦克风、麦线、线结、遥控器、杯子、零食盘、小票、荧光棒、手机、骰子、杯垫和沙锤均为独立透明拖拽精灵。
- 目标态、危险态、可移动态和被压状态统一了视觉反馈；目标麦解锁后自动升层，避免被备用路线的命中框挡住。

v4 已把三关试玩升级为可扩展关卡系统：

- 9 个单关短局，分为基础压层、捷径机制、高压终场三章。
- 首次只解锁第 1 关，过关逐关解锁；星级和最少步数写入浏览器本地记录。
- 入口支持继续未完成关，新增选关页、分关结算、下一关和重玩流程。
- 新增双拉线结、加时棒、泄压物件、开局压力和三路线终关。
- 关卡使用数据字段配置，启动时自动校验重复 ID、缺失依赖、素材类型和目标可达性。
- 详细配置见 `product/level-system-v4.md`。

v5 已针对“整体太简单”增加真正的难度层：

- 第 2-3 关只保留可动数量，第 4 关起关闭物件明暗答案提示。
- 中后期增加总动作上限，误触、绕路和重复拉动都会占用动作。
- 首次选择路线后进入路线承诺，中途换路会扣 2 秒并增加缠线值。
- 第 7-9 关缠线值会随时间持续上涨，错误惩罚同步提高。
- 高危杯子必须拖入撤离区，不能继续靠轻点清除。
- 每关只有一次“观察”，代价是扣 3 秒并失去三星资格。

v5.1 将第 4 关设为明确难度分界：前三关保留教学节奏，第 4-9 关统一收紧时间与动作预算，并逐关提高初始压力、动态压力、换路和误触惩罚。
- 难度参数与验证标准见 `product/level-system-v5.md`。

v6 将后半程从顺序点击升级为七类触控操作：长按断电、往返解结、拖桶停留倾倒、左右摇动、沿线捋线、穿安全门搬运和节拍命中。每种操作都有独立进度与失败反馈，完整规则见 `product/interaction-system-v6.md`。

## H5 与 App 分工

H5：

- 手机点歌入口曝光。
- 20-40 秒完成一个单关挑战，可连续下一关或回到选关页。
- 七类触控动作、双路线选择、最短步数星级、错误反馈、通关结算、挑战文案。
- App 下载或唤起 fake-door。

App：

- 关卡包、每日挑战、同桌最少步数榜。
- 麦克风皮肤、桌面主题、历史成绩。
- 不承接本地生活、门店聚合、陌生人社交或 K 歌主功能。
