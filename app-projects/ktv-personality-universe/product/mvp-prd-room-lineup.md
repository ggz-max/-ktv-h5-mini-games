# KTV 人格宇宙 H5 MVP PRD

## 1. 产品目标

验证一个轻量级 H5/App 雏形是否成立：KTV 用户愿不愿意完成一次人格测试，并把结果当作可收集、可分享的人格卡。

第一版只围绕 3 个核心功能：

1. 测人格
2. 收集人格卡
3. 生成分享图

不做在线 K 歌、不做本地生活、不做陌生人社区、不做付费包和复杂任务系统。

## 2. 核心假设

用户在 KTV 场景里情绪高、社交关系近、愿意玩一点带梗的身份测试。只要人格结果够爽、卡片够像资产、分享图够适合发给朋友，就有机会从一次点歌 H5 变成可持续复玩的轻量产品。

## 3. 目标用户

KTV 包厢内使用手机点歌 H5 的会员用户，优先考虑 18-25 岁朋友局、生日局、同学局、团建局，也兼容中年用户的娱乐心态。

## 4. 成功指标

- 入口点击到开始测人格：>= 45%
- 扫描完成到领取并入档案：>= 35%
- 领取后点击档案库、分享图或再测：>= 25%
- 档案库点击再测或生成分享图：>= 20%
- 分享图保存、系统分享或复制文案：>= 12%

## 5. MVP 链路

1. 入口页：测出你的 KTV 人格
2. 数据生成：基于历史点唱画像直接生成第一张卡
3. 扫描页：伪分析人格倾向
4. 结果页：给出 KTV 人格代码、称号、稀有度
5. 人格卡奖励页：领取并入档案，同屏选择下一步
6. 档案库：展示已收集卡、未解锁卡、下一张目标
7. 分享图内容页：把个人结果组织成可分享人格卡
8. 分享确认页：保存海报、系统分享、复制文案、朋友也来测

## 6. 当前人格

外显人格名采用“简单英文单词 + 中文解释”，内部 code 只用于存档和链接，不直接作为用户理解入口。

- STAR：主场星 / 快歌、开场曲和互动偏好高
- SKIPPER：切歌师 / 切歌、控台和节奏判断偏好高
- LOVER：纯爱者 / 纯情情歌和慢歌偏好高
- JOKER：小丑 / 受伤情歌、入戏和自嘲感强

人格命名原则：短、怪、能自嘲、能让用户觉得“有点像我”，避免犯罪、违法、治安、诊断类表达。

## 7. 页面要求

### 入口页

目标：一眼让用户知道这是娱乐测试，不是问卷。

要求：
- 标题直给：测出你的 KTV 人格
- 副标题明确：30 秒拿到可分享人格卡
- 首屏露出 4 个核心人格词：STAR / SKIPPER / LOVER / ECHO；档案库承载 12 张人格卡
- 直接给奖励预期：今日首测必掉 1 张人格卡
- CTA：开始测人格

### 扫描页

目标：制造仪式感，让测试过程像正在发生。

要求：
- 显示数据来源
- 人格代码闪烁
- 进度条推进
- 3-4 秒自动进入结果

### 结果页

目标：先给啊哈时刻。

要求：
- 人格词要大：STAR
- 称号要有梗：主场星
- 描述要短：你一出手，现场就从观望切到全员放飞。
- 稀有度和掉落卡面要清楚
- CTA：领取并入档案

### 人格卡奖励页

目标：把测试结果变成“我的资产”。

要求：
- 卡面比结果更大、更亮
- 文案明确“人格卡已入档案”
- 同屏展示：已领取、已装备、已入库
- CTA：查看档案库、生成分享图、再测一次

### 档案库

目标：解决一次测完就没下文的问题。

要求：
- 展示已拥有/总卡数、未解锁、连续测
- 当前人格卡可点击看详情
- 每个人格使用独立形象；详情页展示同人格皮肤库
- 未解锁卡可点击看下一次再测动机
- 明确下一张目标，视觉上像卡池锁卡而不是普通列表
- 提供 3 个行动：再开一张、再测一次、生成分享图

### 分享图内容页

目标：把个人结果变成适合发给朋友的人格卡。

要求：
- 中心突出当前人格
- 其他人格作为“朋友也可能是”的引导
- 这是分享图内容形态，不是第四个独立功能

### 分享确认页

目标：降低分享动作成本。

要求：
- 保存海报
- 系统分享
- 复制文案
- 再测一次 / 朋友也来测
- 分享链接带来源人格，只做邀请钩子，不把朋友结果写入自己的档案

## 8. 不做事项

- 不做真实录唱、评分、练歌
- 不做门店/商户聚合
- 不做陌生人社区
- 不做心理诊断
- 不做完整会员商业化包
- 不把包厢阵容扩成第四个核心功能

## 9. 下一步实验

1. A/B 首屏：测出你的 KTV 人格 vs 30 秒抽 KTV 人格卡
2. 用 gpt-image-2 补齐 8 张新增人格卡的独立卡面，提高复玩空间
3. 分享图保存后的群文案测试
4. 档案库下一张目标的视觉强化
5. 如后续接入真实点歌行为数据，只作为加分证据，不作为基础玩法依赖
