# KTV 人格宇宙体验设计 v1

## 产品一句话

KTV 人格宇宙是一套放在手机点歌 H5 里的娱乐人格体验。

它不是心理测试，也不是唱功评分，而是：

> 把今晚的点歌偏好，翻译成一张可以收集、保存、分享的 KTV 人格卡。

当前只围绕 3 个核心功能：

1. 测人格
2. 收集人格卡
3. 生成分享图

## 整体体验原则

### 1. 不做问卷，做“歌单暴露”

用户在 KTV 场景里没有耐心填 20 道题。人格结果应该优先来自：

- 本场点歌
- 歌曲情绪/年代/风格
- 合唱次数
- 切歌/重唱
- 点歌时间点
- 是否带动气氛

如果数据不足，只补 3 个轻问题：

1. 你今晚更像：抢麦 / 潜伏 / 观察 / 起哄
2. 你最怕别人点：苦情歌 / 高音歌 / 土嗨歌 / 新歌
3. 你唱 KTV 的底层动机：释放 / 装酷 / 怀旧 / 搞笑

### 2. 先给强结果，再给解释

第一屏必须先砸结果：

> BOOM 气氛过载源

解释、证据、图鉴都放后面。不要让用户先读说明。

### 3. 个人结果进档案，分享图负责传播

个人结果负责啊哈时刻，档案库负责沉淀，分享图负责传播。

分享图可以使用“包厢人格异常图鉴”的视觉表达，但它属于“生成分享图”功能，不单独扩成第四条产品线。

传播页主文案：

> 发群里，让大家对号入座。

### 4. 轻冒犯，但必须安全

可以损，但不能羞辱。

允许：

- 麦克风长期扣押型人格
- 包厢审美清道夫
- 深夜情绪自动播放装置

避免：

- 现实侮辱词
- 性羞辱
- 真心理疾病
- 暧昧关系默认暴露
- 消费金额/隐私暴露

## 场景链路

### 场景 A：包厢内，唱到一半

用户状态：

- 气氛已经起来
- 有人在点歌/切歌/抢麦
- 适合触发玩梗

入口：

手机点歌 H5 浮层：

> 歌单已经暴露你了  
> 30 秒测出你的 KTV 人格

交互：

1. 点击进入“正在扫描歌单”。
2. 播放 3 秒扫描动效：歌词碎片、麦克风、人格代码闪现。
3. 如果数据够，直接出结果。
4. 如果数据不够，补 3 个轻问题。

适合目标：

- 个人结果
- 当场分享给旁边朋友看

### 场景 B：结账/散场前

用户状态：

- 本场数据更完整
- 情绪还在
- 适合生成分享图

入口：

唱后页 / 结账页：

> 今晚 A08 包厢人格图已生成  
> 发群里，让大家对号入座

交互：

1. 生成个人结果。
2. 引导“生成分享图”。
3. 展示人格图鉴式海报。
4. 保存/分享。

适合目标：

- 群聊传播
- App 下载/打开
- 保存人格历史

### 场景 C：离店后

当前 Demo 不做完整首页，只保留“人格档案库”作为收集感证明。

用户离店后如果再次打开，优先看到：

- 已拥有的人格卡
- 下一张目标
- 再测一次
- 生成分享图

## 信息架构

### H5 入口页

目标：让用户点进来。

页面结构：

1. 大标题：歌单已经暴露你了
2. 副标题：30 秒生成你的 KTV 人格
3. 动态人格代码滚动：MIC-H / BOOM / CUT-X / SAD-FM
4. CTA：开始扫描
5. 辅助：仅供娱乐，可匿名分享

### 扫描页

目标：制造仪式感，不让等待无聊。

动效内容：

- 歌名碎片飞过
- 麦克风扫描光
- 人格代码闪烁
- 文案随机出现：
  - 正在检测副歌统治欲
  - 正在分析切歌冲动
  - 正在计算包厢失控风险
  - 正在读取苦情歌浓度

时长：

- 3-5 秒，不要超过 8 秒。

### 轻问题页

目标：数据不足时补充，不做长问卷。

每题一屏，最多 3 题。

题目示例：

1. 副歌来了，你通常：
   - 直接接管
   - 看别人发挥
   - 偷偷和声
   - 准备切歌

2. 包厢冷场时，你会：
   - 点一首全员会唱的
   - 点一首自己想唱的
   - 开始起哄
   - 假装没看到

3. 你最无法忍受：
   - 副歌没人唱
   - 高音上不去
   - 土嗨歌太多
   - 一首歌太长

### 个人结果页

目标：啊哈时刻。

结构：

1. 人格代码：BOOM
2. 人格名：气氛过载源
3. 一句扎心解释：
   > 你一出手，包厢就从唱歌场所变成集体失控现场。
4. 三个证据：
   - 快歌占比 42%
   - 带起 6 次合唱
   - 气氛峰值出现在你点歌后 38 秒
5. 危险等级：易燃
6. CTA：
   - 领取并入档案
   - 生成分享图

### 分享图页

目标：群聊传播。

结构：

1. 标题：A08 包厢人格异常图鉴
2. 4-6 个角色卡：
   - Leo：BOOM 气氛过载源
   - 小雨：SAD-FM 苦情电台
   - 阿杰：CUT-X 包厢审美清道夫
   - Cici：ECHO 人声回环
3. 包厢总结：
   > 本包厢危险等级：中度失控
4. CTA：
   - 保存分享图
   - 系统分享
   - 复制文案

### 档案库页

目标：收集欲。

结构：

- 已拥有人格卡
- 未解锁人格卡剪影
- 下一张目标
- 再测一次
- 生成分享图

## 核心交互细节

### 1. “换个说法”

结果不准时，不要让用户退出。给一个轻按钮：

> 换个说法

效果：

- 同一个人格，换一版文案。
- 例如 BOOM 可以切换为：
  - 毒舌版
  - 夸夸版
  - 发疯版

### 2. “匿名分享”

分享前让用户选择：

- 显示昵称
- 只显示头像
- 匿名代号

降低隐私焦虑。

### 3. “对号入座”

分享图发出后，朋友点进来可以：

- 认领我是这个
- 反驳：我不是
- 重新生成我的人格

这是传播回流点。

### 4. “隐藏人格”

制造讨论：

- LOVE-BUG：合唱关系异常升温者
- ZZZ：灵魂退出但肉身仍在
- FAKE-V：开口前全是气势型人格

隐藏人格不默认出现敏感解释，只给娱乐化描述。

## 视觉呈现

### 关键词

- 霓虹 KTV
- 伪科学检测
- 人格代码
- 宇宙图鉴
- 异常图鉴/伪检测报告感
- 但整体要可爱、好笑，不阴森

### 页面气质

不是报告页，不是美团，不是工具。

更像：

- MBTI 测试结果
- SBTI 毒舌人格图鉴
- 网易云年度报告
- 游戏角色卡
- 赛博占卜机

### 卡片元素

- 人格代码
- 危险等级
- 包厢作用
- 触发证据
- 稀有度
- 分享短句

## 数据到人格的映射

### 第一版可用规则

| 数据信号 | 可能人格 |
|---|---|
| 连唱多、点歌多 | MIC-H |
| 切歌多、完成率低 | CUT-X |
| 快歌/神曲多、合唱多 | BOOM |
| 慢歌/苦情歌多 | SAD-FM |
| 合唱/跟唱多 | ECHO |
| 高音歌曲多 | HI-R |
| 歌曲跨度大、老歌热歌都接 | PRE-3 |
| 低参与但停留长 | NPC / ZZZ |
| 重复同一歌/歌手 | LOOP |
| 点歌多但实唱少 | FAKE-V |

### 数据不足时

用 3 题轻问卷补齐，不要强行假装很准。

## MVP 版本

### H5 MVP

1. 入口页
2. 扫描页
3. 歌路选择
4. 个人结果页
5. 人格卡奖励页
6. 档案库页
7. 分享图页

## 成功指标

### H5

- 入口点击率 >= 10%
- 测试完成率 >= 65%
- 人格卡领取率 >= 35%
- 档案库打开率 >= 25%
- 分享图生成率 >= 18%
- 再测点击率 >= 12%

## 失败信号

- 用户觉得“不准但不好笑”。
- 用户只看个人结果，不领取并入档案。
- 用户领取后不选择档案库、分享图或再测。
- 分享率低于 8%。
- 结果文案太温和，不能形成群聊调侃。

## 第一版最重要的体验

不要先做完整 App。

先把 3 个动作做到爆：

> 测人格、收集卡、生成分享图。

如果用户愿意测、愿意收进档案库、愿意生成分享图，这个方向才成立。
