# KTV 人格宇宙人格卡体系 v1

## 设计目标

人格卡不是普通测试结果，而是用户愿意收集、展示、分享的轻资产。

第一版卡片体系围绕 4 个主系列扩展到 12 张：

- 热场系：负责把场子点燃
- 控场系：负责管理歌单和节奏
- 情绪系：负责把歌唱成故事
- 合唱系：负责把副歌接住
- 上头/冒险系：负责制造包厢记忆点

## 命名原则

- 英文必须是常见词或近似常见词，用户不看解释也能猜到性格方向。
- 中文不是翻译，而是 KTV 场景里的身份标签：`LOVER（纯爱者）` 对应纯爱情歌，`JOKER（小丑）` 对应受伤情歌和自嘲入戏。
- 内部 code 永远不直接暴露给普通用户；它只负责存档、接口和兼容旧链接。
- 卡片形象要跟人格名一致：JOKER 要有小丑/自嘲舞台感，LOVER 要有纯爱电台感，HOPER 要有流行歌和明亮提气感。
- 避免 `ROMEO` 这类需要典故理解的词作为用户可见人格名；它可以留作内部 code，但用户看到的必须是 `LOVER / JOKER / REPEATER` 这种外号式单词。

## 点歌数据到人格词的翻译规则

这一套命名要像 SBTI 一样，先让用户“看懂自己”，再让朋友“对号入座”。所以每个英文词都必须能被一句点歌画像解释：

| 点歌画像 | 命中人格 | 用户直觉 |
| --- | --- | --- |
| 纯情、告白、甜歌、青春情歌多 | LOVER（纯爱者） | 原来我唱情歌是在讲真心话。 |
| 失恋、受伤、嘴硬、自嘲情歌多 | JOKER（小丑） | 原来我越难过越会装好笑。 |
| 流行热歌、提气歌、全民熟歌多 | HOPER（希望派） | 原来我负责把今晚唱亮。 |
| 快歌、开场曲、第一轮互动高 | STAR（主场星） | 原来我一开唱就像主场。 |
| 切歌、跳前奏、控台操作高 | SKIPPER（切歌师） | 原来我不是扫兴，是救节奏。 |
| 副歌跟唱、自然补位、合唱稳定 | ECHO（回声者） | 原来我不是背景音，是第二层灵魂。 |
| 重复点同一首、本命歌执念强 | REPEATER（复读者） | 原来我不是没歌唱，是这首还没唱够。 |
| 高音挑战、明知危险也要冲 | CHALLENGER（挑战者） | 原来高音对我来说是挑战关。 |

| 控台、原唱、顺序调整多 | BOSS（控场者） | 原来我嘴上随便，实际在管全局。 |

新增人格时先补这张“数据 -> 人格词 -> 用户直觉”表，再补卡面和皮肤。不要先起内部代号，再反向解释。

## 画像命中解释口径

结果页不能让用户感觉像随机抽卡。每张人格卡都必须同时展示三层证据：

- 综合匹配：把当前点歌画像和 12 张人格模型做相似度排序，展示 `匹配 xx%`。
- 维度命中：展示 3 个关键画像维度，并标记 `命中 / 接近 / 有信号 / 低信号`，不要把低指标也说成“偏高”。
- 候选排名：展示 `画像候选 TOP n`，让用户知道这张卡在当前画像中的排名。

首张主类型的解释口径是：`首次主类型来自历史点唱画像：综合匹配 xx% · 2/3 维命中，把你推向 LOVER。`

后续复测的解释口径是：主类型已固定，继续开卡是在相近候选里补图鉴或补同人格皮肤，不要让用户误以为每点一次都是完全随机。

## 卡片深度字段

每张人格卡在 H5 里都需要具备 4 层信息，保证用户点开详情时有收藏感，而不是只看到一句测试结果。

| 字段 | 用途 | 展示位置 |
| --- | --- | --- |
| 人格签名 | 一句最像分享文案的身份宣言 | 卡片详情第一条 |
| 触发证据 | 解释为什么测出这张卡 | 卡片详情第二条 |
| 皮肤设定 | 让卡面有世界观和收藏理由 | 卡片详情第三条 |
| 收藏价值 | 告诉用户这张卡在档案库里的意义 | 卡片详情第四条 |

当前 H5 已为 12 张卡补齐上述字段。后续新增卡片时，不能只补 `code/title/desc/skinArt`，必须同步补齐 `signature/evidence/skinLore/collectValue`。

## 形象和皮肤原则

- 每个独立人格必须有独立角色形象，不能只靠换色区分。
- 同一个人格可以有多套皮肤，详情页必须展示“已拥有 / 未解锁”的皮肤槽。
- 人格头像负责身份识别，卡面皮肤负责收集深度，两者不要混成同一层资产。
- 当前 H5 已接入 12 张独立头像，核心人格先接入多皮肤槽，后续逐步补齐每个人格的专属皮肤分支。

皮肤分支出图规则：

- 同一人格的 3 张皮肤必须共享同一个角色骨架，但姿态、服装、道具、场景情绪要明显不同。
- 不同人格必须有不同轮廓，不能只换背景色。
- 图片内不要出现英文人格词和中文人格名，文字由 H5 渲染。
- JOKER 可以有小丑和面具元素，但不能偏恐怖、犯罪或精神诊断。
- LOVER 要像年轻人的真心话，不要做成油腻情圣。
- HOPER 是希望派和提气者，不是“气氛组”或主持人模板。

## 文案边界

- 不使用犯罪、违法、治安、诊断词。
- 不把人格说成真实心理测评。
- 不羞辱用户，只做自嘲和玩梗。
- 不暗示 App 内有录唱、评分、练歌功能。
