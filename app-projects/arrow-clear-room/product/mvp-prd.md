# MVP PRD：箭头清场王

## 1. 产品概述

箭头清场王是一款放在 KTV 手机点歌 H5 入口里的轻量箭头迷宫解谜小游戏。

玩家看到一屏白底深蓝箭头迷宫线。每条线都有一个箭头方向。玩家只能点击“前方路径畅通”的线段，让它飞出屏幕并消除；如果前方被其他线段挡住，则点击失败且线段不会消失。

一句话：

> 找到能飞出去的箭头，一根根拆开阻挡，清空整屏。

## 2. 背景与约束

- 入口来自 KTV 手机点歌 H5。
- 用户是混合人群，不默认女性向。
- 方向必须轻量、可快速复制。
- 首版必须打开就能玩，有即时反馈、有失败、有不服再来。
- 不做本地生活、重组局、陌生人社交或 K 歌主功能。
- 视觉必须接近成熟小游戏里的白底深色箭头迷宫，不使用 KTV 图标换皮。

## 3. 参考机制

- 《一箭又一箭》：密集箭头迷宫中寻找能冲出去的箭头，路径畅通才清空路线。
- Arrow Puzzle / Tap Away 类产品：箭头或方块只能沿自身方向飞出，必须先清外侧、再解锁被挡住的对象。
- 同类规则：箭头对象沿箭头方向前进，前方被挡则不能移出，出边界则消除。

## 4. 核心假设

1. 用户 5 秒内能理解“前方没挡住才能点”的规则。
2. 少量可走线逐步解锁更多线，会形成解谜感，而不是纯点击劳动。
3. 被挡时红色反馈、正确时飞出动画，能形成明确的即时反馈。
4. 步数、倒计时和清线率能驱动再来一局。

## 5. 核心功能

### 功能 1：箭头迷宫阻挡关卡

- 主棋盘使用 SVG 绘制可计算的白底深蓝箭头迷宫线。
- 每条线段由多段正交折线组成，末端箭头方向决定飞出方向。
- 点击时检查箭头头部沿方向到边界的整条通道。
- 通道中有任何未清线段则判定为被挡，线段红闪且不消失。
- 通道畅通则线段飞出屏幕，清线率、连清和分数更新。
- 每关约 80-90 根线，脚本校验在配置步数内可完整清空。

成功阈值：

| 指标 | 目标 |
|---|---:|
| 开局成功率 | >= 70% |
| 首关通过率 | >= 45% |
| 平均点击次数 | >= 20 |

失败信号：

- 用户觉得画面不是迷宫，只是箭头阵列。
- 用户觉得“随便点都能消”，没有解谜感。
- 用户不知道为什么某根线不能走。
- 10 秒内退出 > 40%。

### 功能 2：进度反馈和不服再来

- 正确清线时更新清线率、连清和分数。
- 被挡误点时扣步数、重置连清、线条红闪。
- 展示剩余步数、倒计时、当前可走线数量。
- 失败后展示“差一点就通了”等评级。

成功阈值：

| 指标 | 目标 |
|---|---:|
| 失败后复玩率 | >= 25% |
| 结果页停留 | >= 8 秒 |

失败信号：

- 用户只玩一局就走。
- 用户觉得被挡反馈不清楚。

### 功能 3：结果分享

- 通关或失败后生成结果页。
- 展示分数、清线率、最高连清、误触次数。
- 生成挑战文案，方便复制发群。

成功阈值：

| 指标 | 目标 |
|---|---:|
| 结果分享/复制点击率 | >= 10% |
| 分享回流率 | >= 5% |

## 6. H5 与 App 分工

H5 做：

- 入口曝光。
- 4 个固定关卡。
- SVG 箭头迷宫棋盘。
- 前方通路阻挡玩法。
- 关卡可解性校验。
- 结果页和挑战文案。
- App 承接 fake-door。

App 承接：

- 更多关卡包。
- 每日挑战。
- 好友排行榜。
- 主题皮肤。
- 历史战绩。
- 赛季称号。

## 7. MVP 成功阈值

| 指标 | 目标 |
|---|---:|
| 入口点击率 | >= 8% |
| 开局成功率 | >= 70% |
| 首关通过率 | >= 45% |
| 平均点击次数 | >= 20 |
| 失败后复玩率 | >= 25% |
| 结果分享/复制点击率 | >= 10% |
| App fake-door 点击率 | >= 3% |
