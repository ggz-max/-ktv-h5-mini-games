# 箭头清场王

## 项目定位

箭头清场王是一款放在手机点歌 H5 入口里的轻量箭头迷宫解谜小游戏。

一句话：

> 满屏箭头迷宫线，只有前方路径畅通的箭头才能飞出屏幕；一根根拆开阻挡，清空全屏。

## 玩法参考

本项目参考的是市面上《一箭又一箭》/ Arrow Puzzle / Tap Away 这一类成熟小游戏，而不是纯点击消除。

核心规则：

- 每条线段末端有箭头方向。
- 点击后，线段沿箭头方向尝试飞出棋盘。
- 如果箭头前方通路被其他未清线段挡住，本次点击失败，线段不会消失。
- 如果前方路径畅通，线段飞出屏幕并消除。
- 清掉外侧线后，会逐步解锁内侧被挡住的线。
- 目标是在步数和倒计时内清空全部线段。

## 为什么做这个

- 方向遵循 `decisions/0003-lightweight-copyable-minigame-benchmarking.md`：轻量、可快速复制、直接上手、有挑战。
- 相比找茬类，箭头逃脱有明确的“可走/被挡”判断，失败反馈更强，也更容易形成“不服再来”。
- 不强行套 KTV 图标，首版直接靠成熟小游戏的白底深蓝箭头迷宫降低理解成本。
- 题材性别中性：规则是路径判断和顺序规划，男性、女性、朋友局、同事局都能理解。

## 当前实现

- `frontend/`：静态 H5 游戏原型。
- `frontend/src/main.js`：生成可解的 SVG 箭头迷宫线，并实现前方阻挡判定。
- `frontend/src/levels.json`：4 个固定关卡配置。
- `scripts/level-tools.js`：关卡生成、阻挡规则、可解性校验。
- `scripts/verify-local.js`：本地 Playwright 验证脚本，会先点被挡线确认不能消除，再按可走序列通关。
- `verification/`：验证截图输出目录。

## H5 与 App 分工

H5：

- 手机点歌入口曝光。
- 4 个固定关卡。
- SVG 可计算箭头迷宫棋盘。
- 前方通路阻挡判定。
- 步数限制、倒计时、通关/失败结算。
- 结果文案和挑战分享。

App：

- 更多关卡包。
- 每日挑战。
- 主题皮肤。
- 好友排行榜。
- 历史战绩和赛季称号。
