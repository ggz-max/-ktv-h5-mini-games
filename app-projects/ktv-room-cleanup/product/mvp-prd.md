# MVP PRD：包厢大扫除

## 1. 产品概述

包厢大扫除是一款放在 KTV 手机点歌 H5 入口里的轻量堆叠消除小游戏。

用户在 30-90 秒内点击并清理包厢里的杂物：麦克风、遥控器、骰子、酒杯、零食、荧光棒、纸巾、歌单牌等。三个相同物件自动清走，底部清理槽满了则失败。

一句话：

> 把乱成一团的包厢清掉，差一点失败也能发群挑战。

## 2. 背景与约束

项目背景：

- 入口来自 KTV 手机点歌 H5。
- 用户是混合人群，不应默认女性向。
- 方向要轻量、可快速复制，优先借鉴成熟小游戏机制。
- 不能做成本地生活、重组局、陌生人社交或 K 歌主功能。

参考机制：

- `抓大鹅` / `羊了个羊`：堆叠消除、差一点失败、不服再来。
- 货柜消除：物件分类、清空空间。
- 收纳整理：从混乱到整齐的视觉爽感。

## 3. 目标

验证用户是否愿意：

1. 在手机点歌 H5 里点击一个轻小游戏入口。
2. 不看长说明就完成第一局核心操作。
3. 失败后再来一局。
4. 通关或失败后保存/分享挑战结果。
5. 对 App 承接的每日挑战、关卡包、排行榜或皮肤产生兴趣。

## 4. 非目标

MVP 不做：

- 完整 App。
- 复杂关卡编辑器。
- 多人实时联机。
- 门店真实排行榜。
- 付费系统。
- 会员权益。
- 商户券、附近推荐、组局履约。
- 录唱、练歌、唱功评分。

## 5. 目标用户

### 核心用户

KTV 包厢内使用手机点歌 H5 的年轻用户，18-25 岁为主，男女混合。

典型场景：

- 点歌空档。
- 等朋友唱完。
- 朋友在选歌，自己短暂无事。
- 包厢气氛已经热起来，适合玩一个 1 分钟挑战。

### 外延用户

- 同事局、生日局、同学局、中年朋友局。
- 分享链接进入的群友。

要求：

- 首屏必须让不同性别、不同年龄用户都能看懂。
- 文案可以玩梗，但不能过于抽象。

## 6. 核心假设

### 假设 1：KTV 用户愿意在点歌 H5 里点一个 90 秒小游戏

如果入口足够具体，比如“这个包厢太乱了，90 秒清干净”，用户会比抽象“小游戏中心”更愿意点击。

### 假设 2：堆叠消除机制可快速迁移到 KTV 物件

麦克风、酒杯、骰子、零食、遥控器等物件天然适合做可识别图标；用户不需要理解 KTV 数据，也能直接玩。

### 假设 3：失败结果比通关结果更容易传播

“差一点清完”“清理槽爆了”“A08 包厢救不回来了”这类失败反馈，会驱动用户再来一局或发给朋友挑战。

## 7. 最核心的 3 个功能

### 功能 1：90 秒包厢清理局

#### 目标

让用户 5 秒理解玩法，30 秒进入状态，90 秒内完成一局。

#### 玩法规则

- 游戏区展示多层堆叠的包厢物件。
- 用户点击可触达的物件。
- 被点击物件飞入底部清理槽。
- 清理槽内 3 个相同物件自动消除。
- 清理槽最多 7 格。
- 槽满且无法消除时失败。
- 所有物件清空时通关。

#### 首版物件

首发 10 类，保证性别中性：

- 麦克风
- 遥控器
- 骰子
- 酒杯
- 零食盘
- 纸巾
- 荧光棒
- 歌单牌
- 充电线
- 切歌按钮

#### 关卡结构

MVP 做 6 个固定关卡：

1. 新手桌面：少量物件，必通。
2. 零食风暴：轻度堆叠。
3. 麦克风缠线：增加遮挡。
4. 遥控器失踪：目标物件在下层。
5. 酒杯不要倒：清理槽压力增加。
6. A08 终局：高难，制造分享和不服。

#### 成功指标

- 入口点击率 >= 8%。
- 开局成功率 >= 70%。
- 首局停留时长 >= 30 秒。
- 新手关完成率 >= 60%。

#### 失败信号

- 用户点击入口后 10 秒内退出超过 40%。
- 用户不知道哪些物件可点。
- 新手关完成率 < 35%。

### 功能 2：差一点救场

#### 目标

失败不应只是结束，而要让用户觉得“刚才差一点，我能过”。

#### 机制

失败时展示：

- 本局清理进度，例如 `清理了 82%`。
- 还差的关键物件，例如 `还剩 2 个麦克风、1 个骰子`。
- 包厢评级，例如 `轻度失控 / 重度失控 / 彻底摆烂`。
- 再来一局按钮。
- 一次“救场道具”按钮。

#### 救场道具

MVP 只做 2 个：

- 撤回一步：把上一次点击物件放回原位。
- 清空一组：从清理槽里移除一个指定物件类型。

道具获取：

- 首局失败免费给 1 次。
- 后续通过分享挑战或 App 承接 fake-door 获取，不接真实广告。

#### 成功指标

- 失败后再来一局率 >= 25%。
- 救场道具点击率 >= 20%。
- 使用救场后继续玩 20 秒以上比例 >= 60%。

#### 失败信号

- 失败后直接退出率 > 70%。
- 用户觉得失败太随机、不可控。
- 道具说明复杂，点击率 < 8%。

### 功能 3：结果海报与同局挑战

#### 目标

让失败和通关都能成为群聊传播物。

#### 结果类型

通关结果：

- 标题：`A08 包厢清理完成`
- 评级：`整洁王 / 清场大师 / 包厢救星`
- 数据：用时、剩余槽位、连消次数。
- CTA：`发给朋友挑战同一局`

失败结果：

- 标题：`A08 包厢清理失败`
- 评级：`差一点就能救回来`
- 数据：清理进度、卡住物件、槽位爆点。
- CTA：`让朋友接着救`

#### 分享链路

- 用户点击分享结果。
- 生成结果图和挑战链接。
- 朋友打开链接后进入同一关卡 seed。
- 朋友完成后看到与发起人的对比：
  - 用时更短。
  - 清理进度更高。
  - 是否通关。

#### 成功指标

- 结果页停留 >= 8 秒。
- 结果图保存/复制文案/系统分享点击 >= 12%。
- 分享链接回流率 >= 5%。
- 同局挑战完成率 >= 30%。

#### 失败信号

- 用户只玩不看结果页。
- 保存/分享点击 < 5%。
- 朋友打开后不知道要挑战什么。

## 8. 用户流程

### 首次进入

1. 手机点歌 H5 展示入口：`这个包厢太乱了，90 秒清干净`
2. 用户点击进入包厢大扫除。
3. 展示 2 秒玩法提示：
   - `点物件进清理槽`
   - `三个一样自动清掉`
   - `槽满就翻车`
4. 进入新手关。
5. 完成或失败。
6. 展示结果页。
7. 引导再来一局或分享挑战。

### 分享回流

1. 用户收到挑战链接。
2. 首屏展示好友成绩。
3. CTA：`挑战同一间包厢`
4. 进入相同 seed 关卡。
5. 结果页对比两人表现。

## 9. 页面清单

| 页面 | 目的 | 关键组件 |
|---|---|---|
| 入口页 | 让用户点击开局 | 包厢乱桌视觉、90 秒挑战、开始按钮 |
| 玩法提示层 | 降低学习成本 | 3 条短提示、可跳过 |
| 游戏页 | 核心体验 | 堆叠物件、清理槽、进度、倒计时/步数 |
| 失败页 | 促使再来 | 清理进度、失败原因、救场道具、再来 |
| 通关页 | 强化爽感 | 用时、评级、下一关、分享 |
| 结果海报页 | 传播 | 结果图、复制文案、同局挑战链接 |
| App 承接页 | fake-door | 每日挑战、好友榜、皮肤、关卡包 |

## 10. 文案方向

### 入口文案

- 这个包厢太乱了，90 秒清干净
- A08 已经乱到不能点歌了
- 清完这桌，今晚你就是包厢救星

### 失败文案

- 差一点，麦克风还是埋在下面
- 清理槽爆了，包厢选择继续摆烂
- 你已经救回 82%，但骰子不愿意走

### 通关文案

- 包厢恢复可见状态
- 今晚这桌被你救回来了
- 清场大师已上线

### 分享文案

- 我差一点清完这个包厢，你来
- 这局真的能过，不信你试试
- A08 清理挑战，我卡在 82%

## 11. H5 与 App 分工

### H5 做

- 入口曝光。
- 6 个固定关卡。
- 单局核心玩法。
- 失败救场。
- 结果海报。
- 同局挑战链接。
- App 承接 fake-door。

### App 承接

- 每日挑战。
- 更多关卡包。
- 好友挑战榜。
- 物件皮肤。
- 包厢主题皮肤。
- 历史战绩。
- 限时活动。

App 第一阶段不承接：

- 真实门店排行。
- 商户券。
- 本地生活。
- 陌生人广场。
- 复杂账号关系。

## 13. MVP 成功阈值

| 指标 | 目标 |
|---|---:|
| 入口点击率 | >= 8% |
| 开局成功率 | >= 70% |
| 首局 30 秒停留率 | >= 55% |
| 新手关完成率 | >= 60% |
| 失败后再来一局率 | >= 25% |
| 结果分享/保存/复制点击率 | >= 12% |
| 分享链接回流率 | >= 5% |
| App fake-door 点击率 | >= 3% |

## 14. 失败信号

- 入口点击率 < 3%：主题不吸引或入口位置不对。
- 首局 10 秒内退出 > 40%：规则不够直观或 UI 误导。
- 新手关完成率 < 35%：难度过高。
- 失败后再来一局率 < 10%：不服循环没建立。
- 分享点击 < 5%：结果没有社交货币。
- 男性用户访谈反馈“这不是给我玩的”：题材偏差，需要回到更中性物件。

## 15. 后续可复制皮肤

如果包厢物件首版成立，同一套机制可换皮：

- 宿舍大扫除。
- 工位大扫除。
- 奶茶小料清理。
- 旅行箱大扫除。
- 朋友圈显眼包清理。
- 年会桌面清理。

每个皮肤只换物件、美术、文案和关卡布局，不改核心机制。

## 16. 首版交付建议

第一版只做一个可玩 H5，不做完整后端：

- 静态关卡 JSON。
- 本地埋点暂存。
- Canvas 或 DOM 实现点击、飞入槽、三消、失败和通关。
- 结果海报可先用 DOM 截图或 Canvas 合成。
- 分享链接可用 URL seed 模拟。

目标是在 3-7 天内做出可现场试玩版本。
